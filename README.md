# 智能围裙｜教师数字平台

澳门大学任老师课题组的教师数字平台 P0 交互原型。通过虚构案例演示教学目标、教学环节、故事与围裙反馈配置、教案审核、课堂记录和课后复盘。

## 运行

需要 Node.js 和 npm。在项目目录执行：

```powershell
npm.cmd install
npm.cmd run dev
```

打开终端显示的本地地址。执行 `npm.cmd run test` 运行规则测试，执行 `npm.cmd run build` 检查 TypeScript 并构建生产版本。

## 原型边界

本项目使用虚构儿童资料，内容保存在当前浏览器的 localStorage。AI 建议、围裙设备连接与传输、课堂事件和复盘均为模拟，没有接入真实 AI 或硬件，不能用于诊断或疗效判断。详细状态见 [PROJECT_PROGRESS.md](PROJECT_PROGRESS.md)。
