## 开工前的只读调查结论（根目录 Codex 版本）

- 已有：React 19 + TS + Vite、Context + reducer、三阶段课程工作区、候选采纳、锁定、版本快照、模拟传输、复盘审核、8 条规则测试。
- 值得重新设计的点：
  1. 模拟 AI 基本返回固定模板（不随目标文本变化，换写法只是前缀“备选写法：”）。
  2. 目标、限制修改后的下游复核、旧异步结果拒绝依赖整体修订号，缺少逐环节的内容修订号。
  3. 围裙反馈只区分 visual/audio，无法检查“避免突然大音量”等限制是否被违反。
  4. 复盘只有“观察/建议”两段文本，没有区分事实、模拟记录、AI 推断与未知。
- Hark 版本**没有复制旧版代码**，模型、规则、页面、样式均重新编写；只借鉴了“候选采纳”“批准快照”的业务思路与同一演示案例。

## 已知问题与限制

- 未在 Windows / Edge / Safari 上实测；端到端脚本默认使用 `/usr/bin/chromium`，其他系统需通过 `CHROMIUM` 指定浏览器路径。
- 未配置 ESLint；代码风格靠 TypeScript strict 与人工检查。
- 无撤销栈（旧版有 20 步撤销）；本版以“候选不直接写入 + 确认锁定 + 替换前对比”降低误操作，撤销留待后续。
- 仅一个虚构儿童；环节“作用”（引入/示范/练习/减少提示/回顾）在 P0 固定，新增环节默认为“引导练习”。
- 未经真实教师使用测试；以上验证只能说明流程与规则可运行，不能说明教学有效性。
