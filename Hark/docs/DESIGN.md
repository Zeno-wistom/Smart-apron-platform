# Hark UX 受控重构 · 体验规范

更新：2026-10-28。基线 PR #1 / `hark/independent-v01` @ `24b5b8d`；本分支只修改 `Hark/`。

## 教师任务与信息架构

一级导航保持「教学工作台 / 儿童档案 / 教学记录」。活动只有「备课 / 课堂与复盘」两个模式。

- 工作台只列一次同一活动；当前单儿童原型中新建直接进入目标编辑，名称可在顶栏改。
- 备课是一张教案纸面：教学目标、环节轨道；每节关联教师引导、儿童互动、观察方式、故事呈现和围裙提示。
- 故事不是独立阶段；保留整体梗概、角色、全部场景按教学顺序连续阅读。单节编辑与整体叙事共用同一批 `Scene.stepId`。
- 参考抽屉覆盖显示，不挤压正文。课前检查收集最终审核；完整教案与历史快照只读查看、可打印。
- 课后一次生成课堂记录与复盘。来源默认分为事实 / 模拟记录 / AI 推断 / 未知，修改时才打开分类控件。归档前预览具体观察与来源版本，也可仅完成复盘。

## 视觉与密度

- 暖纸色 `#f5f3ee`，深海绿 `#2e5a4f`，琥珀只提示 AI 建议，锈橙用于阻断/限制冲突。
- 主稿白纸面，内部以间距、分隔线区分；避免每段重复套卡片。AI 以细线和轻背景表达。
- 正文/输入 15px，按钮及常规 UI 14px，辅助信息 13px；字体权重 400/500/600/700。`--fs-11`/`--fs-12` 兼容旧样式名，但实际均为 13px。
- 主要文字 `--ink`，辅助文字 `--ink-3 #59635d`；不以装饰色承载必要信息。
- 当前主意图使用 primary；参考、导航、生成/换写法和编辑操作保持次级。对话框中的主操作取代被 inert 的背景操作。
- 页面级「原型模拟」常驻，说明见提示及课前检查；避免逐卡重复模拟徽标。

## 布局

- 活动顶栏 56px；不再叠加 52px 阶段条。儿童、版本与完整教案入口放在内容元信息行。
- ≥1440px 保留 208px 主导航；961–1439px 主导航缩成 64px 图标列，保留可访问名称。
- 备课轨道 184px，纸面最大 824px（正文 760px）。1366px 实测正文 760px。
- <1024px 轨道改为默认收起的环节选择器；<640px 两模式和保存状态进入元信息行，活动顶栏仍为 56px。
- 参考/课前检查抽屉覆盖式；手机全宽。一次只展开一个环节，完整故事线按需打开。

## 教师控制与安全

- 整课候选和单节改写都先预览。整课只补空白，支持取消个别条目、采纳所选；部分采纳时不附上基于未采用内容的故事。源 revision 改变后立即失效。
- 单节改写显示将替换字段及原文；已批准快照只读，继续修订不改历史。
- 围裙按结构化限制筛选默认建议。已选配置不被自动覆盖；替换时展示当前/建议。限制排除项与原因在环节、课前检查中可见；人工选入冲突提示仍阻断。
- 最终勾选展示完整内容与范围。`plan/approve-ready` 只合并内部确认，不清除复核标记或候选；再执行原 `plan/approve` / `blockingIssues`。
- 快照保存成功后才能连接、模拟传输。失败重试沿用同一个 versionId；回执保存失败不假报保存成功。
- 批量复核显示原教案/当前目标、受影响内容和完整故事；有些历史数据没有原目标文本时明确说明，不伪造差异。
- 撤销/重做仅保留本次页面编辑的最近 40 步，覆盖文本、环节增删；不跨批准/继续修订边界，不改版本快照。恢复会递增修订号并清除旧候选；目标/限制恢复仍触发下游复核。

## 空、错与恢复

- 空白：先写目标与观察方式；生成按钮说明影响范围。
- AI/传输失败：保留正文、提供重试；没有真实外部调用。
- 保存失败：常驻错误与重试；批准快照未保存时禁止传输。
- 损坏存储：暂停自动保存，允许下载原始数据，重置须显式选择。
- 缺场景可补充，环节删除后的原故事场景保留并要求重新关联；空内容/孤立场景仍阻断。

## 无障碍与验证边界

所有主导航有名称；skip link 可到主要内容。Modal/Drawer 打开后背景 inert、焦点陷阱、Esc 关闭、焦点归还；修复链接将焦点送到目标字段。可滚动课堂事件可键盘聚焦。动效尊重 reduced-motion。

实际浏览器、截图、axe 与测试见 [UX-REFACTOR-REPORT.md](UX-REFACTOR-REPORT.md)。自动化/专家审查不等于真实教师可用性研究；本轮不宣称真实教学效果或硬件有效性。
