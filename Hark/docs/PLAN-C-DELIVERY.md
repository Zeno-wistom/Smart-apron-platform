# 方案 C 最小可运行版

日期：2026-10-30。基线 cd152ba；独立分支 codex/apron-plan-c。未改动 main、PR #1 或 PR #2，未推送合并。

## 运行与体验

在本工作树 Hark 目录执行 `npm run dev -- --host 127.0.0.1 --port 5186 --strictPort`。
本次已启动 http://127.0.0.1:5186/ 。浏览器数据仅保存在该地址的本地存储中。

准备一堂课 → 填写或选择目标、观察方式与备注 → 根据这些目标安排课程 → AI 建议简短安排 → 采用并调整活动目的、数量、顺序与故事使用 → 按安排生成教案 → 使用初稿 → 通读教案/故事/围裙互动 → 编辑一个环节 → 检查并完成备课 → 最终确认 → 单独模拟传输。

左下角“原型工具”可设置下一次模拟传输失败；失败后再点传输，已批准版本不变。

## 实现与边界

- 新建活动进入四项任务路径。目标页提供明确下一步，不提前显示详细生成或全课缺项计数。
- 简短安排与详细稿分别生成候选、主动采纳。目标和教师修改的活动目的进入模拟展开；活动数量可在展开前增删、上移排序。
- 整课阅读优先，局部 AI 显著展示，采纳前保留教师原文。普通编辑自动保存，无逐节锁定。
- 故事保留主题、梗概、角色和连续讲述，允许部分活动不使用。非故事活动独立配置反馈，并继续检查未知提示、声音、闪烁和暂停规则。
- 教案完成与传输分别反馈；保存失败不宣告完成，传输失败沿用批准版本重试。
- 使用可选 courseFlow 扩展，未升级旧 envelope；旧稿沿用旧界面与检查，旧批准快照不迁移或修改。完整教案和模拟课堂读取新版独立反馈。

本轮限制：详细展开后暂不支持活动结构增删重排，可修改文字、时长、故事开关和围裙配置。AI 仍是模板模拟，局部改写尚无自由指令对话。故事使用按活动控制，尚未实现任意多对多故事片段关联。真实 AI、设备、儿童数据及研究有效性均未验证；正式研究对故事的要求待核实。
